# Contributors

- [yuetanbupt](https://github.com/yuetanbupt)
- [ElephantsGit](https://github.com/ElephantsGit)

This list acknowledges project contributions. It does not grant repository
permissions or create Git authorship records.

GitHub's automatic **Contributors** graph is generated from qualifying commits
on the default branch. Each contributor should author a real contribution using
an email linked to their GitHub account and have that contribution merged. For
a genuinely coauthored commit, use a `Co-authored-by: Name <verified-email>`
trailer with that person's correct identity. Do not fabricate commits or author
identities solely to populate the graph. Updating this file requires no action
from the listed contributors.

To grant write access, the repository owner can open **Settings → Collaborators
(or Collaborators and teams) → Add people**, invite `yuetanbupt` and
`ElephantsGit`, and have each person accept. Access invitations are separate
from acknowledgment and automatic contribution attribution.
