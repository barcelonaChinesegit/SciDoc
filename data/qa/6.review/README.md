# Retained QA review evidence

This directory contains review evidence that directly supports a retained
release.

- `cross_pdf/` contains the batch-1 manual review packet and decisions. It is
  evidence for the formal Cross-PDF source component, not a duplicate dataset.
- `final_2200_modalities/` contains the Claude Sonnet 5 per-question visual
  modality audits for all 2,200 final questions.

Web accounts, review state, event history, and undo snapshots live separately
under `data/web/review/`.
