# Cross-PDF 证据页错误分解报告（历史 400 题）

> 本报告保留旧批次实验记录，不能代表当前 final_2200 的 Cross-PDF 800 题。旧路径对应归档中的原始成员；±1 页容忍是历史误差诊断，当前论文主指标采用精确物理页的宏平均 P/R/F1 与 A-Pages，完全页集合匹配仅为诊断。下文“当前”“这次”指该历史实验时点。

## 结论先行

这次 Cross-PDF 400 的 GPT-5.6 结果不应解释为“模型完全找错了证据页”。本报告将 **±1 物理页容忍的页级 Precision / Recall / F1** 作为主要定位分析；严格页集合完全相等（exact-set）仅保留为最小引用遵从度的对照。更准确的结论是：

1. GPT 的页码输出在 400/400 条中都合法、排序唯一、落在合并 PDF 范围内；400/400 条预测到的源文档集合与金标源文档集合一致。
2. 在 ±1 页口径下，GPT-5.6 的宏平均 P/R/F1 为 **64.24% / 83.30% / 70.34%**，微平均为 **58.23% / 83.95% / 68.76%**。这比严格同页的 39.84% / 68.31% / 48.14% 更能反映相邻页选择后的实际定位覆盖。
3. 两个正式 Qwen3VL 结果在同一口径下仍低于 GPT：4B 的宏平均为 **46.20% / 54.14% / 44.89%**，8B 为 **50.47% / 62.72% / 50.54%**。因此此前“答案较弱的 Qwen 严格页准确率略高于 GPT”的反转，不会出现在允许相邻页的页级 P/R/F1 上。
4. 严格“预测页集合与金标集合完全相等”只有 25/400（6.25%）。错误页中，主要构成为“多报页”或“部分命中且同时多报/漏报”，而不是完全不相交：
   - 仅多报页：143/400（35.75%）；
   - 部分命中、同时有漏页和多报页：187/400（46.75%）；
   - 仅漏页：4/400（1.00%）；
   - 完全不相交：41/400（10.25%）。
5. GPT 人工判定的 100 条 stride-4 子集显示答案正确率 91/100（91.00%），严格精确页命中只有 4/100（4.00%）；但其 ±1 宏平均 P/R/F1 已达 63.49% / 84.55% / 70.29%。其中 87/91 条答案正确题页集合没有严格精确命中，说明答案理解与最小证据集合选择是两个明显不同的能力。

因此，当前现象的首要原因是**严格最小页集合指标与模型实际提供的充分证据集合不一致**，其次才是相邻页偏移、漏页和真正检索错误。该历史诊断不构成修改金标准或改用容忍页评分的依据。当前论文主结果按语义 Answer Accuracy、宏平均精确页级 P/R/F1 和 A-Pages 报告，exact-set 仅为审计诊断；±1 页分析如保留，必须独立标明历史输入与诊断口径。

## 1.1 页码编码规则核查

这次专项核查没有发现“模型使用源论文页码、评测却使用合并 PDF 页码”这一编码错位。实际规则如下：

1. Cross-PDF 数据集和每个合并 PDF 都声明 `physical_pdf_page_1_based`。例如 `xb_0024.pdf` 共 78 页：Doc 1 是合并页 1–15，Doc 2 是合并页 16–56，Doc 3 是合并页 57–78。因此该题的金标 `[16, 57]` 确实指合并 PDF 的第 16 页和第 57 页，而不是两篇论文各自印刷的“第 16 页”和“第 57 页”。
2. 金标 `evidence_items` 同时保存 `physical_pdf_page` 和 `source_page`。映射关系是：
   `physical_pdf_page = merged_start_page + source_page - 1`。
   对完整 GPT 400 条逐条核验，400/400 条的每个 `evidence_item` 都满足这个关系。
3. 评测输入端的 PDF 渲染使用 `pdf[page_number - 1]`，即内部 0-based 索引转换为外部 1-based 页号；随后在每张图像前明确写入 `[Page N]`。系统提示明确要求模型使用外部 `[Page N]`，禁止使用论文页眉、页脚或正文中的印刷页码。
4. GPT 400 的结果元数据同时标记 `pdf_page_numbering` 和 `evidence_page_numbering` 为 `physical_pdf_page_1_based`。400/400 条的模型页码在合并 PDF 范围内，且每个完整 PDF 的输入标签是 `[Page 1]` 到 `[Page N]`。
5. 4B/8B 的评测也通过同一套规则运行：400/400 条输入展示页为完整的合并 PDF 1..N，推理记录中的 `reference_evidence_pages` 与金标一致，Judge 记录中的 `reference_evidence_pages` 也与金标一致，预测页全部属于展示页。
6. Judge 没有做“源论文页码到合并页码”的二次转换，也没有做 ±1 页、减去文档起始页等隐式修正。它在规范化排序后直接比较 `predicted_evidence_pages == reference_evidence_pages`。因此当前低 exact 页准确率不是由评测阶段编码规则不一致造成的。

生成金标时确实发现过 1 条审核响应把 Doc 3 的 source-local page `3` 写入了 `merged_page` 字段；构建器按 Doc 3 起始页 37 转换为物理页 39，并把修复记录在 `annotation_provenance.page_numbering_repairs`。最终发布金标使用的是修复后的 `[4, 39]`，不是错误的 `[4, 3]`。这是一条已处理的构建阶段输入修复，不是测试阶段的统一偏移。

## 2. 主要指标：±1 页容忍的 Precision / Recall / F1

令去重后的金标物理页集合为 `G`，预测物理页集合为 `P`。本报告的主要页级指标采用容忍半径 `d = 1`：

```text
precision_hit = {p in P : exists g in G, |p - g| <= 1}
recall_hit    = {g in G : exists p in P, |p - g| <= 1}
Precision     = |precision_hit| / |P|
Recall        = |recall_hit| / |G|
F1            = 2 * Precision * Recall / (Precision + Recall)
```

这是**邻域成员关系，不是一对一匹配**。例如 `G = [3]`、`P = [2, 4]` 时，预测页 2 和 4 都距离金标页 3 不超过 1，故 Precision = 2/2、Recall = 1/1、F1 = 1；不能把其中一页强行判为重复命中。这样做准确落实了“金标第 3 页时，预测第 2 或第 4 页均算对”的规则，也会如实保留多报相邻页对 Precision 的影响。

每题先独立计算 P/R/F1 后取算术平均得到**宏平均**，使每道题权重相同；把所有命中页数和所有预测/金标页数先汇总再计算得到**微平均**，使页数较多的题权重较大。空预测页集合的该题 P/R/F1 均记为 0。Qwen 的 P/R/F1 只在结构化输出合法的题上计算，非法输出另行报告，不能伪装成页码定位结果。

严格 exact-set 仍用于下列错误分类和历史结果对照，不再作为本报告判断“证据页是否正确”的主要数值：

| 类型       | 判定                           | 解释                             |
| ---------- | ------------------------------ | -------------------------------- |
| exact      | `P == G`                       | 严格页集合完全正确               |
| over-only  | `P > G`                        | 全部金标页都报到了，但额外多报页 |
| under-only | `P < G`                        | 只漏页，没有额外页               |
| partial    | `P ∩ G` 非空，且既不是以上三类 | 部分命中，同时漏页和/或多报页    |
| disjoint   | `P ∩ G` 为空                   | 没有命中任何金标页               |

作为辅助诊断，报告还保留：

- `any overlap`：`P ∩ G` 非空；
- `complete recall`：`G ⊆ P`，允许多报页；
- 严格同页的页级 Precision/Recall/F1；
- 预测页和金标页的源文档集合是否一致；
- 金标页是否在预测页的 ±1、±2、±3 物理页邻域内。

±1 指标不修改不可变金标，也不修改正式 Judge 的严格协议；它衡量的是相邻物理页也可作为同一局部证据的诊断性定位质量。它不能自动证明相邻页一定包含完整语义支持，严格 exact-set 仍保留以衡量最小金标页集合的可复现性。

### 3.1 页集合错误组成

| 类别                       | 数量 |   比例 |
| -------------------------- | ---: | -----: |

| over-only                  |  143 | 35.75% |

### 3.2 主要结果：±1 页容忍定位质量

400 条合计金标页 997 个，GPT 预测页 2,035 个。按第 2 节的 ±1 非一对一规则，1,185 个预测页落在至少一个金标页的邻域内，837 个金标页被至少一个预测页覆盖：

| 指标 | 数值 |
| --- | ---: |
| 金标页数，均值/中位数 | 2.49 / 2 |
| 预测页数，均值/中位数 | 5.09 / 4 |
| 预测页数多于金标页数 | 340/400（85.00%） |
| **±1 宏平均 Precision / Recall / F1（主要）** | **64.24% / 83.30% / 70.34%** |
| **±1 微平均 Precision / Recall / F1（主要）** | **58.23% / 83.95% / 68.76%** |
| 严格同页宏平均 Precision / Recall / F1（对照） | 39.84% / 68.31% / 48.14% |
| 严格同页微平均 Precision / Recall / F1（对照） | 33.76% / 68.91% / 45.32% |

在允许一页边界偏移后，GPT 仍表现为**证据集合过宽**：召回 83.30% 明显高于精度 64.24%，预测页总数约为金标页数的 2.04 倍。相较严格同页，Recall 增加 14.99 个百分点、Precision 增加 24.40 个百分点，说明一部分严格失败确实是相邻页选择；但 Precision 仍不是满分，故不能把问题归结为纯粹的统一页码偏移。仅漏页也不是主导错误。

### 3.3 文档级与邻页诊断

GPT 400/400 条的预测源文档集合都与金标源文档集合一致。例如金标需要 Doc 1+Doc 3 时，GPT 没有把页码报到 Doc 2，而是在 Doc 1/Doc 3 内选择了额外页。因此不能把主要问题归因于合并 PDF 的文档边界或文档 ID 映射错误。

以金标页为中心检查物理页距离：

| 容忍范围       |          覆盖全部金标页的题数 |
| -------------- | ----------------------------: |
| 精确同页（±0） | 168/400（42.00%，允许额外页） |
| ±1 页          |             273/400（68.25%） |
| ±2 页          |             311/400（77.75%） |
| ±3 页          |             340/400（85.00%） |

这说明有一部分 exact 失败是相邻页选择或页内证据布局差异，而不是完全错误的检索。273/400 的“覆盖全部金标页”与主要 ±1 Recall 的 83.95% 并不相等：前者必须每一金标页都被覆盖，后者按页累积计算，二者回答不同问题。

### 3.4 GPT 人工判定的 100 条子集

`CrossPDF100` 的人工标签为：

| 指标               |   数量 |                比例 |
| ------------------ | -----: | ------------------: |
| 答案正确           | 91/100 |              91.00% |
| 精确页命中         |  4/100 |               4.00% |
| 答案与页同时正确   |  4/100 |               4.00% |
| 至少一个页命中     | 94/100 |              94.00% |
| 答案正确但页不精确 | 87/100 | 占答案正确题 95.60% |

页集合类别为：exact 4、over-only 35、partial 53、under-only 2、disjoint 6。类别与答案标签交叉后：

- 35 条 over-only 中 32 条答案正确；
- 53 条 partial 中 48 条答案正确；
- 2 条 under-only 全部答案正确；
- 6 条 disjoint 中 5 条答案正确。

因此答案正确而页不精确的 87 条中，80 条仍属于 over-only/partial，只有 5 条是答案正确但页完全不相交。这个结果直接支持“页码集合选择比答案语义判定难，并且 exact-set 对多报页非常敏感”的结论。

人工子集在主要 ±1 口径下的页级宏平均为 Precision 63.49%、Recall 84.55%、F1 70.29%，与完整 GPT 400 的 64.24%/83.30%/70.34% 基本一致，说明 100 条子集的页码行为具有代表性。严格同页的宏平均为 40.29%/68.78%/48.49%，保留为历史对照。

## 4. 典型错误案例

### 4.1 答案正确、全部金标页都覆盖，但多报页

`xb_0024/QA3`：

- 金标：`[16, 57]`；
- GPT：`[16, 17, 24, 25, 57, 59, 60, 61]`；
- 答案：人工判定正确；页集合为 over-only；严格同页 P/R/F1 为 25% / 100% / 40%。

Doc 2 的 16/17 页是统一音频文本模型的摘要和退化问题，24/25 页是训练流程和数据混合，Doc 3 的 57/59/60/61 页是 LoRA-MoE 的摘要、贡献和结构。GPT 的长答案确实展开了这些训练与架构细节；金标只保留每个来源事实的最小代表页。因此这里主要是“充分证据集合”与“最小金标集合”的差别，而不是文档找错。

### 4.2 答案正确、部分命中并混入相邻页

`xb_0054/QA7`：

- 金标：`[1, 26]`；
- GPT：`[2, 3, 26, 27]`；
- 答案正确；页集合为 partial；严格同页 P/R/F1 为 25% / 50% / 33.33%。

Doc 1 的 1 页是 CASL-VAE 摘要，2/3 页继续解释 unpaired data 和 latent variation；Doc 3 的 26/27 页是 clustered-data 模型和图示，27 页是相邻的结构图页。预测没有换文档，只是没有选择金标指定的 Doc 1 首页并额外选择了相邻页。

### 4.3 答案正确、严格不相交，但接近金标页

`xb_0092/QA3`：

- 金标：`[1, 16]`；
- GPT：`[2, 17]`；
- 答案正确；页集合为 disjoint；
- 两个预测页分别只比两个金标页偏移一页，属于典型的页边界/摘要到引言页选择，而不是跨文档错位。

这类样本在 exact-set 下记为 0，但在 ±1 页诊断下会被识别为近邻命中。

### 4.4 答案正确但确实漏页

`xb_0126/QA12`：金标 `[3, 4, 9, 12]`，GPT `[3, 9, 12]`。这是 under-only，严格同页 P/R/F1 为 100% / 75% / 85.71%。这种“答对但漏掉一个必要证据页”的情况存在，但在 GPT 400 中只有 4 条，不是主导项。

在答案已经正确的题上，4B 只有 18/115 页精确，8B 只有 24/122 页精确；也就是说，Qwen 的“答案正确但证据页不精确”同样普遍。4B/8B 还出现了若干连续报出几十页的合法输出：合法不等于定位质量高，结构化 JSON 通过只说明格式正确。

### 5.2 Qwen3.5 API 试跑

两个 Qwen3.5 输出文件合并去重后共 121 条尝试，其中 107 条没有形成可解析的证据页 JSON，只有 14 条有可分析页码：exact 1、over-only 5、partial 7、under-only 1。该试跑未完成 400 条，也没有对应答案人工判定，不能用于与 GPT/4B/8B 比较准确率；它主要说明 API 运行失败率很高，不能作为稳定 benchmark 结果。

### 5.3 对比结论

GPT 的页码行为是中等宽度但系统性过报：平均 5.09 页、中位数 4，主要 ±1 宏 P/R/F1 为 64.24%/83.30%/70.34%；Qwen3VL 4B/8B 的典型输出中位数都是 2，但部分题会输出 20–100 页的连续区间，形成很长的尾部并拉低 Precision 和联合指标。其 ±1 宏 F1 只有 44.89%/50.54%，均明显低于 GPT。模型规模从 4B 增长到 8B 后，答案、严格页和邻页容忍定位指标均上升。因此这不是 GPT 单独的异常，而是 Cross-PDF 中普遍存在的“语义回答与最小证据定位不同步”问题；GPT 的差异在于其较强答案常伴随过度引用，而不只是完全无关的错页。

### 5.4 为什么较弱模型有时页准确率反而高于 GPT

这个现象只发生在**严格 exact-set**，不表示较弱模型的跨论文理解或实际邻页定位更好。严格规则下 GPT 为 25/400（6.25%），Qwen3VL-4B 为 31/400（7.75%），Qwen3VL-8B 为 44/400（11.00%）；但改用本报告的 ±1 P/R/F1 后，GPT 的宏 F1 为 70.34%，明显高于 4B 的 44.89% 和 8B 的 50.54%。Qwen 的答案端到端准确率也只有 28.75%/30.50%，远低于 GPT 在人工判定 100 条子集的 91.00%。这里应同时看以下四层事实。

1. **exact-set 同时考察页数和页号，不考察答案。** 400 条中 298 条（74.50%）金标恰好有两页。Qwen3VL-4B/8B 的合法输出分别有 235/398（59.05%）和 224/399（56.14%）也恰好报两页；GPT 只有 36/400（9.00%）报两页，页数中位数为 4。这会使 Qwen 更容易满足 exact-set 的“基数”条件，即使其答案只抓到了摘要级模式或漏掉了推理限定条件。
2. **Qwen 的精确页成功并不必然带来答案正确。** 4B 的 31 个 exact 页样本中只有 18 个答案也正确，另有 13 个是“页正确、答案错误”；8B 的相应数字是 44、24 和 20。页码可能已经落在标注者选定的两张代表页，但模型仍可误读页内关系、做错跨文档比较或给出错误结论。严格页指标因此不是答案能力的代理变量。
3. **GPT 的答案扩展会直接伤害 exact-set。** GPT 的预测页均值/中位数为 5.09/4，Qwen4B/8B 的中位数都是 2（尽管少数连续报页的长尾使其均值达到 9.17/9.03）。GPT 对两页金标的 exact 是 23/298，却为这些题平均报 4.71 页；它通常先形成较完整的解释，再为解释中的训练、机制、实验背景一并引用页面。Qwen 更短或更模板化的回答有时只需引用摘要/首个代表页，反而更贴合金标的最小集合。这个“命中”是定位与答案粒度共同造成的，不可解释为更强的证据推理。
4. **改用邻页 P/R/F1 后，页数巧合不再能轻易制造反转。** Qwen 的两页输出仍可能恰好配上金标的两页数目，但只要页号落得不在金标周围，Precision 和 Recall 都会下降；GPT 的相邻页选择则获得合理信用。因而 GPT 的 ±1 Recall 为 83.30%，高于 Qwen 4B/8B 的 54.14%/62.72%，而 GPT 的 Precision 也为 64.24%，高于 46.20%/50.47%。这不是答案标签配对比较，而是同一金标上的纯页面集合比较。

因此，出现“答案低、页 exact 略高”并不怪异，而是两个不相同的随机变量：

```text
答案正确 = 选对来源事实 + 正确组合/推理 + 正确表达
页 exact = 选对全部金标页 + 不漏页 + 不多报页
```

后者既不检查答案语义，也不奖励“额外页仍真实支持答案”。一个模型可以仅凭两个摘要页通过页 exact 后仍答错；另一个模型也可以充分答对，却因多报一页得到零分。±1 P/R/F1 缓和了相邻页的偶然边界惩罚，但仍会惩罚与所有金标页都不相邻的多报页。只有联合指标才要求答案和页面同时成立。

## 6. 为什么会出现答案高、证据页低

### 原因 A：金标是最小代表页，模型输出的是充分证据页

当前 `evidence_pages` 是 Claude 审核后重建的代表性支持页集合，通常每个来源事实保留一页。它不是“所有能支持答案中每个细节的有效页面集合”。GPT 的答案平均约 1,098 个字符，而金标答案平均约 372 个字符；GPT 展开了训练、架构、实验等额外事实，就会自然引用更多页面。只要 exact-set 仍是唯一判定，这些有效额外页都会被判错。

### 原因 B：页码是物理页，证据常跨摘要、引言和方法边界

摘要页、下一页引言、图注页和方法页都可能支持相同的高层结论。`[1,16]` 与 `[2,17]` 这种样本表明模型理解了相同文档证据，但选了相邻物理页。全 GPT 400 中 68.25% 的题可在 ±1 页覆盖全部金标页，进一步说明页边界效应明显。

### 原因 C：Cross-PDF 需要同时定位多个文档，最小集合约束比答案生成更脆弱

模型必须先识别 Doc 1/2/3 的关系，再从每个文档选出最少页。答案可以只要语义等价；页集合却要求每一页都正好属于金标集合。多文档题的答案只要抓住每篇论文的中心结论就可能正确，但页定位还要恢复构造者选择的具体物理页。

### 原因 D：Qwen 还存在显式的连续区间过报

4B/8B 的部分输出把大量连续页放入 `evidence_pages`。这不是“答案页完全找不到”，而是证据选择器没有形成最小集合，或者将“我看过的页面”与“支持答案的页面”混淆。它会严重拉低 exact-set 和 Precision。

### 原因 E：模型的“答案粒度 - 引用粒度”策略不同

GPT 往往输出超出金标短答案的机制和背景，并在相同的“所有实质支持页”要求下报出更多页；Qwen 的低答案准确率意味着它常只保留高层、局部或错误的结论，而其观察到的两页输出分布恰好与多数最小金标的两页形式相同。前者主要承担 extra-page 的 exact 惩罚，后者则会出现“页对、推理错”。这解释了**严格 exact 分数的反转**；当 ±1 近邻页也获得信用时，GPT 的较高覆盖与较低的无关页比例重新反映在 P/R/F1 上。

### 已排除的主要原因

- 不是统一的全局页码偏移：GPT 400/400 条均在物理页范围内，且源文档集合 100% 对齐。
- 不是主要由漏页造成：GPT 仅漏页的 under-only 只有 4 条；多报页参与了 330 条错误集合。
- 不是单纯输出格式问题：GPT 400/400 条结构化页码合法；Qwen 的格式/请求失败则单独计入其合法率，不应与页检索错误混为一谈。

## 7. Benchmark 是否需要改进

### 不建议做的事

不要直接把现有金标页集合改成模型输出的并集，也不要删除 exact-set 指标。这样会破坏当前 400 条的可复现性，并可能把“模型多看、多报页”错误地奖励成证据正确。

### 建议在论文前完成的改进

1. **以 ±1 P/R/F1 为主，保留 exact-set 对照。** 主表报告 ±1 page Precision/Recall/F1、document-level source recall、`complete recall (G ⊆ P)`，并在附属列保留严格 exact-set 与严格同页 P/R/F1。这样审稿人可以区分“相邻页选择”“多报有效页”和“完全错页”。
2. **增加页到事实的对齐。** 对每个必要来源事实记录 `evidence_group` 或可接受页集合，而不是只有一个最小代表页；模型输出页只要每个必要事实至少命中一个可接受页即可。原有 exact-set 作为严格子指标保留。
3. **把证据页输出限制为最小集合。** 下一版提示要求每个必要 source document 只返回支持最终答案的最少页，并要求逐页给出一句 `page_claim`。设置合理上限或“每个来源最多 1–2 页”可以抑制 4B/8B 的连续区间，但不能对已有结果做事后截断。
4. **区分答案内容和证据内容。** 如果答案允许自由扩展细节，金标也应记录这些细节的可接受页；否则应要求模型只回答金标答案粒度。当前 GPT 的长答案与短金标之间存在明显粒度差。
5. **做一次分层人工复核。** 从 exact、over-only、partial、under-only、disjoint 五类各抽样，并分别覆盖答案正确/错误；重点核查额外页是否确实支持答案中新增事实。这个审计结果可以作为 supplementary material。

### 是否要重做这 400 条

若论文主张是“跨文档答案理解能力”，不需要重做 400 条，现有数据可以保留；但必须把 exact page accuracy 明确称为“最小金标页集合精确命中率”，同时公布宽松诊断指标。若论文主张是“可审计证据定位能力”，则建议发布一个版本化的 v4 evidence-group 标注集，并把当前 v3 作为 strict legacy benchmark，而不是悄悄改金标。

## 8. 给审稿人的解释模板

可以在论文中这样解释：

> We report answer correctness and evidence localization separately because they test different capabilities. Our primary localization analysis uses page-level precision, recall, and F1 with a +/-1 physical-page tolerance: every predicted page within one page of any gold page receives precision credit, and every gold page with such a prediction receives recall credit. On the full 400-item GPT-5.6 output, this yields macro P/R/F1 of 64.24%/83.30%/70.34%, versus 46.20%/54.14%/44.89% for Qwen3VL-4B and 50.47%/62.72%/50.54% for Qwen3VL-8B. We retain exact-set matching against the minimal, auditable page set as a strict reproducibility diagnostic, rather than treating it as the sole evidence-localization result. Adjacent-page credit does not alter gold labels or prove semantic sufficiency; it reduces a known physical-page-boundary penalty while still penalizing unrelated extra pages.

中文说明可以概括为：答案正确说明模型抓住了跨论文关系和结论；严格 exact 低说明模型没有稳定复现构造者选定的“最小代表页集合”。本报告以 ±1 页 P/R/F1 衡量实际的邻页容忍定位覆盖，严格指标保留用于可审计的最小引用对照；两者回答不同问题，不能互相替代。

## 9. 可复现性与限制

- GPT 400 的页码分类是确定性的集合运算；答案正确率只在 `CrossPDF100` 人工子集上有直接人工标签。
- Qwen3VL 4B/8B 的答案和页标签来自统一 Judge，仍应对争议样本做人工敏感性分析。
- GPT 100 条答案标签、Qwen 400 条 Judge 标签和其他 API 原始输出并非同一个配对、同一次 pipeline 的答案评测；本报告只把已经有独立判分的数字称为答案准确率。
- 旧 Reasoning 100 的模型结果仍可追溯，但其 98 条已被审计修订，不能作为当前新增/刷新 Reasoning 数据集的性能结论。
- “额外页是否语义有效”需要逐页人工复核；本报告用 `xb_0024/QA3` 等代表性案例说明机制，不把所有额外页自动宣布为有效。
- ±1 容忍规则是本报告的事后诊断口径，不改变正式 `pdf` 协议中的严格页集合判断，也不应用于既有联合准确率；每个指标的分母均已明确列出，不能把审核接受率或页重合率称为答案准确率。
